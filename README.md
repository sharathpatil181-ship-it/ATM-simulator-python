# 🏧 ATM Simulator (Python + MySQL)
📌 Project Overview

The ATM Simulator allows users to log in using their card number and 4-digit PIN. After successful authentication, users can perform different banking operations such as checking their balance, depositing and withdrawing money, viewing transaction history, and changing their PIN.


This is a console-based ATM Simulator built using:

- ✅ Python with OOP concepts
- ✅ MySQL Database Integration
- ✅ MySQL Connector/Python
- ✅ Command Line Interface (CLI)

## 📦 Features

- Card number & PIN authentication
- Balance checking
- Deposit & withdrawal
- Transaction history
- Change PIN
- MySQL database storage
- Input validation and error handling

## ⚙️ Setup Instructions

1. Create the `atmdb` database in MySQL.
2. Update the database credentials in `database.py`.
3. Install the required package:
   ```bash
   pip install mysql-connector-python
4. Run the project
   ```bash
   python main.py
